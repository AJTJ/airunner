**Scope.** Independent re-check of the load-bearing external claims and sources in the adopter's notes
`agent-protocol-prior-art.md`, `agent-checkpointing-prior-art.md`, `orphaned-resource-recovery.md`,
`build-concurrency-prior-art.md`, `build-concurrency-standard.md`, `api-reachability-prior-art.md`,
`benchmarking-under-load.md` (all under `private/research/adopter-notes/notes/`), plus the parts of
`multi-agent-systems-literature.md` that digest §4.1 leans on for the in-range items (lease-break vs
split-brain, "Do NOT retry" vs starvation, reconciling reaper vs quiescence), and the digest
`private/research/adopter-research-corpus.md` §1.3/1.4/1.10/1.11/1.13/1.15/1.16, §3, §4.
Locally-measured facts (Darwin probes, `cargo --version`, `sysctl kern.sysv`, `which` results) are
not re-runnable from here and are marked LOCAL — only their external framing is checked.

**Method.** For each claim: quote with `file:line`, locate the primary source, fetch it (WebFetch /
WebSearch), compare, verdict from {CONFIRMED, MISQUOTED, OVERSTATED, UNVERIFIABLE, SUPERSEDED, LOCAL}.
Where the claim bears on Air's design (a Rust binary keeping leases in SQLite, journaling events,
supervising a few coding-agent processes on macOS, bounding concurrent cargo builds) a
"newer evidence 2026" pointer is added, including which Rust crates expose the named primitive.
Written incrementally; rows appear in the order verified.

**Date.** 2026-08-18. All URLs accessed 2026-08-18 unless noted.

- **`ReentrantLock` "far lower overall throughput"** — the Javadoc says "lower overall throughput (i.e., are slower; often much slower)… but… guarantee lack of starvation" (row 49). Quote the real sentence; it helps the starvation argument more.
- **"eight open jobserver-rs issues"** — 13 open items today; the substance (none about reclamation) is unchanged (row 11).
- **"A bakery algorithm in about eight lines of shell"** — it is a ticket lock; bakery is the wrong name (row 52).
- **`benchmarking-under-load.md:79` "`make fleet` refuses unlabelled timings above load 2"** — advisory only, per the corpus's own retrospective (row 54).
- **"Does cargo honour `--jobserver-auth=fifo:PATH` on Darwin? — untested, the whole recommendation is conditional"** — overstated as an unknown: the client code path is unconditional POSIX (`open(path, O_RDWR)`), cargo ignores `-j` when a jobserver is inherited (with a warning), and GNU make 4.4 itself uses FIFO jobservers on macOS. Only an end-to-end scheduling observation is outstanding (rows 3-5).
- **"whether nextest joins a make jobserver" as open** — the nextest runner does not (row 14).
- **"Hooks fire on SIGKILL: predicted no"** — still undocumented, but not a research question: SIGKILL cannot run user code. Do not spend another search on it (row 44).

## Claims strengthened

- **`SEM_UNDO` is applied at `exec()` on Darwin** — corroborated in XNU source (`bsd/kern/kern_exec.c` calls `semexit(p)`), so the probe result is designed-in behaviour and a documented divergence from POSIX. A resident supervisor is the only working shape (row 23).
- **jobserver-rs's "no release on abnormal exit"** — verbatim in the current 0.1.35 docs, and make NEWS across 27 years has no reclamation entry (rows 1, 8).
- **Kubernetes level-triggered principle, controller resync, probes; systemd watchdog; RMI DGC leases + sequence numbers; Candea & Fox; Young 1974** — all quoted verbatim and correctly (rows 27-30, 32, 46-47).
- **Claude Code statusline / hooks facts** — verbatim; the hooks page has grown to 31 events (`PostCompact`, `SubagentStop`, `TaskCompleted`) but none is a death signal, which reinforces the "sweep, don't hook" conclusion (rows 43-45).
- **Lease-break ↔ split-brain coupling** — the reasoning holds against Kleppmann/Chubby; and it dissolves for Air if the supervisor, not the agent's tool calls, drives the heartbeat (row 56).
- **Rust crate coverage for every named primitive** exists today: `jobserver`, `libc` (SysV sem on Darwin), `nix::fcntl::Flock`, `nix::sys::event` (kqueue `NOTE_EXIT`), `process-wrap` (row 33).

## Gaps worth new research

1. **End-to-end probe**: `mkfifo`, pre-fill N tokens, `MAKEFLAGS="-j --jobserver-auth=fifo:PATH" cargo build` on macOS 26 — measure rustc concurrency. Ten minutes; closes the last conditional (row 5).
2. **Air as parent-owned admission controller**: design where Air holds the build count (spawn/`waitpid`), and each build gets its own `jobserver::Client::new(width)` — the `jobs`/`cores` split with no shared FIFO to leak. No prior art found for shared-machine multi-agent builds; the notes' "we would be first" stands (row 58; corpus §4.2 G5).
3. **`FIONREAD` on `O_RDWR` FIFO on Darwin** — reproduce and root-cause in XNU (`bsd/kern/sys_pipe.c` / `fifofs`) before anyone builds an audit on it (row 58).
4. **Claude Code hook behaviour on SIGTERM/SIGINT** (not SIGKILL) — undocumented; a five-minute experiment would tell Air whether a graceful `SessionEnd` row can be expected when Air itself terminates an agent with SIGTERM (row 44).
5. **Sidekiq Pro `super_fetch`, Celery `acks_late`, Chubby lock-delay, Blasgen 1979 convoy, Google SRE cascading, AWS jitter, MAST** — not re-fetched this pass (well-known, low risk of misquote); a future pass could close them.
6. **Metastable failures newer work** — Huang et al. OSDI 2022 *Metastable Failures in the Wild* for the load-207 incident mapping (row 50).
