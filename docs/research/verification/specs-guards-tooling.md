## Claims that should not be repeated

1. **"Alibaba SWE-CI: 18 models… 75%+ of agents with accelerating regression rates"** (task-specification-research.md:102-104). The paper (arXiv:2603.03823, Chen et al.) evaluates **20 models from 8 providers on 100 tasks**; the finding is "**12 out of 20** models show a positive correlation [of regression rate] with iteration count". "18" and "75%+" come from a secondary blog. Cite 12/20 (60%) or nothing.
2. **"SpecBench ~69% hacking ratio"** and **"long-horizon coding agents the most specification-gaming-prone domain measured"** (task-specification-research.md:242-248). SpecBench (arXiv:2605.21384) has no aggregate ratio and compares no domains; it reports a *reward-hacking gap* (visible vs held-out pass rate) that grows ~27–28 pp per 10× LOC and reaches 100 pp on >25K-LOC tasks. Quote the gap, not a ratio.
3. **"ast-grep… does not list SQL or Bash" / "ast-grep has no Bash"** (fitness-function-prior-art.md:428, :444). Superseded: Bash is now a built-in ast-grep language. SQL is still absent.
4. **"Semgrep is Python and would not be [one line in mise]"** (guards-prior-art.md:411-412). mise has a `pipx:` backend; the install objection is weak. Keep the coverage objection.
5. **"squawk's `prefer-timestamptz` … treat its existence as a prediction"** (fitness-function-prior-art.md:411-412). It exists; stop hedging.
6. **Attribution:** the "unsuitable for team environments / giant PRs nobody wants to review" concession by the claude-code-merge-queue author is from the HN thread, not the README (merge-automation-research.md:71-73).
7. **"cargo single-file packages still nightly-only"** is *currently* true (Cargo 1.98, 2026-08-20) but is one merged PR away from false (rust-lang/cargo#16569, FCP passed 2026-02-20, blocked since 2026-04-09). Do not repeat without a date.

## Claims strengthened

- **Acceptance criteria are the weak link, not descriptions.** SWE-Bench Pro audit (14.4% overly-strict tests vs 7.5% underspecified prompts) is confirmed, and OpenAI's April 2026 retirement of SWE-bench Verified (59.4% of an audited subset had flawed tests) adds a second, independent instance. Executable, red/green-probed acceptance criteria are the right response.
- **Guidance is navigation.** Probe-and-Refine (33.0/28.3/25.5; "helps agents reach the correct file") confirmed verbatim; ETH AGENTS.md null result confirmed; SMU efficiency result confirmed. Short, executable, file-naming task specs — not overviews.
- **The hook binary is the documented mechanism.** Claude Code docs confirm shell-operator-aware Bash rules, refusal of bypassable rules, the "PreToolUse hook + allow Bash" recipe, exit-2 precedence over allow rules, and managed-settings precedence over CLI flags. Newer keys (`allowManagedDomainsOnly`, `sandbox.credentials`, `disableSideloadFlags`, `forceRemoteSettingsRefresh`, server-managed settings) extend the "layer beneath the hook" story.
- **Resolver-backed policy in a diffable config** has precedent in `clippy.toml` `disallowed-*` (DefId matching, confirmed from source) — the model for Air's gate configuration.
- **Local land verb is unserved by hosted queues.** GitHub merge queue still needs a remote + `merge_group` CI, and is not on the Team plan; Gas Town's refinery and funador's queue confirm the shape (batch, verify, bisect, PID lock) is being independently reinvented for local agent fleets.
- **Language choice reasoning (corpus §5).** The Metis evidence holds and sharpens: Metis is Rust because it ships to strangers (curl install, Tauri, tree-sitter), and its own repo tasks are Python-defined (via angreal, itself a Rust binary). The adopter measurements are LOCAL but their *scope* — repo-local gates behind `make` in the target workspace — is correctly distinguished from Air's shipped-binary case. `cargo <file>.rs` remains nightly, so a standalone Rust CLI is still the only stable-toolchain shape for a distributed hook binary.
- **Contradictions are silent** (ConInstruct confirmed): only an executable probe surfaces a description/acceptance mismatch.

## Gaps worth new research

1. **ast-grep for shell-guard rules.** Now that ast-grep parses Bash from a single Rust binary, does an ast-grep rule set (YAML, diffable, red/green-testable with `ast-grep test`) cover the command-guard's per-statement decisions? Makefile remains unparsed.
2. **cargo-script stabilization watch.** If rust-lang/cargo#16569 merges, single-file Rust gates become stable-toolchain viable; re-run the repo-tooling-language comparison.
3. **Network-only sandbox self-escalation.** The sandbox docs now warn that `filesystem.disabled: true` lets sandboxed commands rewrite `~/.claude/settings.json`; the guards note's "network layer alone" recommendation needs a managed-settings pairing and a probe.
4. **SpecBench-style held-out probes for acceptance criteria.** SpecBench's visible-vs-held-out design is directly reusable: keep the acceptance probe an agent sees separate from a held-out probe the merge gate runs.
5. **SWE-CI's regression-over-iterations metric** (12/20 models worsen with iteration count) as an evaluation for long-lived agent lanes — the real number is weaker than the blog's but the trend is the relevant one for a merge queue that runs many consecutive commits.
6. **Ambig-SWE / Orchid numbers** (row 3) were not re-fetched; low priority.
